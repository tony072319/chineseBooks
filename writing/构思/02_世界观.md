# 02 · 世界观

## 核心三层

```
┌─────────────────────────────────────┐
│  表层（日常）                        │  所有人过的日子：地铁、外卖、996
├─────────────────────────────────────┤
│  阴影层（夜行）                      │  异常存在活动之地；持灯人工作区
├─────────────────────────────────────┤
│  深渊（不可知）                      │  阴影层深处；谁也没完整去过又回来
└─────────────────────────────────────┘
```

### 表层
- 现代中国，21 世纪 20 年代，故事发生在**江城**（虚构一线城市，暗合武汉 + 杭州气质）
- 所有普通人只能感知这一层
- 阴影层入口遍布城市（某些灯柱、老宅、废弃医院、地铁末班车、隧道、桥底、城中村巷口）
- 普通人会"偶尔感觉不对劲"、"说不清的寒意"——这都是阴影层渗透

### 阴影层
- 与表层共存的另一重空间，**只有夜晚活跃**（20:00 - 05:00）
- 外观是熟悉的城市，但：
  - 路灯是昏黄的
  - 行人看不见了，却能看到"另外的存在"
  - 声音变闷，水流倒流，钟表停摆
  - 时间流动大致和表层同步，但有波动
- 长时间待在阴影层对人体有代价（视力损伤、失眠、失去部分记忆、极端情况精神失常）
- 持灯人能自主进出，**普通人会被吸进来但难出去**

### 深渊
- 阴影层的**更深层**，几乎不被提及
- 传说古时持灯人祖师有人下过深渊
- 祖父**疑似**在深渊失踪（第二卷核心线索）
- 到底是什么？—— 留给第三卷揭示

## 异常存在分类

这是全书的"素材库"，每次任务主角会遇到一种。

| 类别 | 示意 | 危险等级 | 成因 |
|------|------|---------|------|
| **游魂** | 路灯下徘徊的模糊人影 | 低 | 找不到归宿的残念 |
| **灯笼魂** | 附着在灯具上的小魂体 | 低 | 旧物件里的情感寄托 |
| **执念体** | 婚礼上永远不走的新娘 / 孩子 | 中 | 未完成的心愿 |
| **古物精** | 老旧物件（铜镜/玉佩/旧书）里的意识 | 中 | 年代久远 + 精神寄托 |
| **回响** | 某个历史瞬间的循环重演 | 中 | 重大事件在阴影层留下的痕迹 |
| **镜中人** | 镜子里的"另一个你" | 高 | 规则生物，极危险 |
| **错位者** | 应死不死/该在不在的人 | 高 | 被其他因素截留的灵魂 |
| **裂口** | 阴影层和深渊之间的破口 | 极高 | 不明 |
| **归墟者** | 从深渊爬出来的东西 | 极高 | 卷二末才出现 |

### 引渡规则（持灯人的"业务守则"）
1. **异常不分善恶**，只分"迷路"和"归位"
2. **不能强制** —— 灯只是指引，不是驱赶
3. **有代价** —— 每次引渡都消耗"灯油"（主角体内的血脉力量）
4. **有限期** —— 有的异常只能在特定时间引渡，错过就要等下次
5. **有禁忌** —— 绝不能在阴影层熄灭自己的灯（持灯人的死亡契约）

## 持灯人（主角阵营）

### 起源
- 上古时代，部落中的"夜巡者"
- 商周时期已有文字记载，称"司夜"
- 宋代确立"持灯"这个名字，灯从火把演化而来
- 现代中国传承极薄弱，全国已知的在册持灯人不到 **50 人**

### 现代组织：持灯公会
- 总部：**北京某不起眼的中医药研究所**（对外身份）
- 分会：几个主要城市（江城分会在老码头区一栋改造的仓库）
- 结构：
  - **长老会**（3-5 位，最高决策）
  - **外勤持灯人**（一线处理异常）
  - **联络员**（对接新老持灯人、处理公众案件，**林雾就是**）
  - **分析员**（档案 / 异常图谱 / 案件复盘）
  - **财政**（官方与公会有某种秘密默契，经费有限但够用）

### 身份识别
- 持灯人的"血脉"可以通过特殊仪式验明
- 大部分持灯人是**传承**（祖父传孙 / 老师传徒）
- 极少数是"野生觉醒"（极偶然被阴影层认可）
- 主角陈烛是**纯血传承 + 强血脉浓度**，百年一见

### 持灯人的信条
> "异常非敌。迷途者，需引路人。"
> "灯熄之日，守夜无人。"

## 吹灯人（反派阵营）

### 起源
- 原本是持灯人内部的分裂派（宋末元初）
- 主张："所有异常都是污秽，必须彻底消灭"
- 持灯派反对："异常也有情感，我们是引路人不是刽子手"
- 分裂后吹灯人转入地下，成为对立面

### 现代组织：暗风会
- 无固定总部，组织松散如地下教派
- **核心人物**：风行舟（第一卷末反派露面）
- 手段：**特制黑烛**可以直接"吹灭"异常（毁灭灵魂层面）
- 与持灯公会的**冷战默契**：互不公开撕破脸，只在事件现场博弈

### 吹灯人的信条
> "净化即秩序。"
> "灯火不灭，异常不绝。"

### 为什么读者不会简单地觉得吹灯人是"纯坏"
- 吹灯人里也有**信念真诚的理想主义者**（风行舟就是）
- 他们的逻辑是可理解的：异常确实会伤人，引渡太慢
- 但他们的手段过激，**消灭了很多"本可被引渡"的异常**
- 到第三卷，主角甚至会被吹灯人说服动摇 → 再做出自己的选择（成长弧）

## 时间线（全书已安排，但慢慢揭）

- 约 **3000 年前**：夜巡者时代
- 约 **1000 年前**（宋末）：持灯人 vs 吹灯人分裂
- 约 **80 年前**（抗战时期）：持灯人大量死于战乱，组织崩溃重建
- **50 年前**：祖父陈守夜成为持灯人
- **30 年前**：某次"大事件"，持灯公会损失惨重（和深渊有关，主角第二卷揭开）
- **1 年前**：祖父突然衰老加速（陈烛感觉爷爷"变老了"）
- **故事开始**：祖父去世 / 失踪，陈烛继承

## 基调细节（影响所有后续写作）

### 要的氛围
- **秋冬夜雨的城市**：湿漉漉的路面、车灯拉长的光、24 小时便利店的白炽光
- **日常与异常的交界**：在便利店买完关东煮，转身就要去引渡一个灯笼魂
- **温情底色的悬疑**：异常大多不是怪物，是"没说完的话、没走完的路、没告别的人"
- **节制的神秘**：世界观不一次讲透，读者跟主角一起慢慢理解

### 不要的氛围
- **纯恐怖猎奇**：不为了吓人而吓人
- **主角无敌爽**：陈烛至少到卷二中后期还会被碾压
- **黑暗压抑到底**：每一次引渡结束要给读者一点"温度"

## 读者情感主轨

全书读者追看的三层动力（从浅到深）：

1. **"这次是什么异常？怎么引渡？"**（单元剧追更）
2. **"祖父到底怎么了？"**（长线悬念）
3. **"陈烛会选择什么样的持灯人之道？"**（角色成长）

前 20 章主要靠 1，卷一末加入 2，卷二打开 3。

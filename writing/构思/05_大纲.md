# 05 · 大纲

## 全书三卷

```
卷一 · 初燃         卷二 · 引路         卷三 · 长明
（1-30 章）         （31-80 章）        （81-150+ 章）
30 万字             50 万字             70+ 万字

陈烛接过灯          进入更大世界        决定自己的路
```

目标总字数：**150-200 万字完本**
章节字数甜区：**2500-3500 字/章**（参照斗破/天道图书馆/诡秘等数据）

## 卷一《初燃》（第 1-30 章）

### 卷目标
- 主角从"普通失业青年"过渡到"勉强能独立工作的学徒持灯人"
- 世界观**逐步展开**：异常、阴影层、持灯公会、吹灯人
- 揭露祖父秘密的**第一层**：他是持灯人，他失踪那天灯熄了

### 结构节奏

```
第 1-3 章  · 楔子         → 开篇三章模板
第 4-8 章  · 学徒          → 5 个小异常，建立世界规则
第 9-14 章 · 公会          → 进入组织，认识搭档、同事
第 15-20 章 · 吹灯人        → 第一反派出现，理念冲突
第 21-27 章 · 小 boss        → 城南博物馆事件，老许亮相
第 28-30 章 · 卷一高潮      → 祖父秘密的第一层，卷一 cliff
```

### 第 21-30 章（卷一末高潮）· 简纲

- **21-23 章**：城南博物馆发生异常升级，老许出手帮忙；陈烛第一次见识到"长明灯"的影子
- **24-26 章**：沈栖梧**意外撞见**了陈烛用灯引渡异常；兄弟间短暂紧张后达成新的信任
- **27 章**：暗风会针对江城分会的一次协同行动；林雾受伤
- **28 章**：陈烛独自应对一次小 boss 级事件（执念体联合）；**灯升级到风灯形态**
- **29 章**：事件后，陈烛在祖父书房墙壁的夹层里，找到一**封未寄出的信**
  > "…如果哪天我没了，孩子，灯交给你。但有一件事我一直没敢跟你讲——**我没死过**，只是一直在**等**。"
- **30 章（卷一大结局）**：陈烛握紧那封信，决定**正式加入持灯公会**；镜头切到暗夜，一个身影（祖父？）在城市另一端点燃了一盏**陈烛看不见的灯**

### 卷一的 3 个钩子（读者追到卷二的动力）
1. **祖父到底怎么了？**
2. **风行舟为什么既对抗又欣赏陈烛？**
3. **那封信上说"没死过"是什么意思？**

## 卷二《引路》（第 31-80 章）

### 卷目标
- 陈烛成为**正式持灯人**，开始接跨区任务
- 深入持灯 vs 吹灯的世界观，接触国家机构**特侦三处**
- 卷末：揭示**30 年前大事件**的部分真相，祖父仍未"完全"归来

### 节奏结构（简）

- **31-40 章**：正式入会，跨城任务（高铁上的幽灵车厢 / 另一座城市的古宅）
- **41-50 章**：**大事件**线索展开，阿骨发现档案空页里藏着的密码
- **51-60 章**：主角 vs 风行舟的**一次重要对决**（第一次暴露深层矛盾）
- **61-70 章**：**官方特侦三处**介入；陈烛认识到除持灯 / 吹灯外还有第三视角
- **71-80 章**：**深渊异常**第一次爬出阴影层；林雾遇险 + 老许露真本事

### 卷二末的 3 层钩子
1. **祖父曾经"下过"深渊？**
2. **暗风会的目标比想象更大**
3. **持灯人自己有可能被同化 —— 主角该怎么办？**

## 卷三《长明》（第 81-150 章+）

### 卷目标
- 主角**独立判断**：他是继承祖父的路，还是走自己的路？
- 深渊真相揭露
- 持灯 vs 吹灯 vs 深渊三方的**最终抉择**
- 祖父"真正"归来 / 和解 / 告别

### 核心问题（贯穿卷三）
- **什么是"真正的引渡"？**
- 对一个真心相信"清除是慈悲"的吹灯人，我们应该说服他，还是战胜他？
- 面对深渊里的"大存在"，灯能不能照明所有黑暗？

### 结局基调（备选）
- **A · 温暖现实主义**（默认）：陈烛成为新一代长明，祖父传承画上句号；林雾并肩；故事温暖收尾，留一个"下一盏灯"的悬念（便于写番外或二部）
- **B · 悲壮英雄主义**：陈烛以燃尽自己为代价引渡了深渊异常，化为一盏长明灯永远守护江城 —— 文学上更厚重，但番茄读者可能不爱
- **C · 开放式**：陈烛做出一个让所有阵营都惊讶的选择，故事不完全闭合，留给读者想象

## 预写但不剧透给读者的"长线伏笔"清单

这些是我们作者知道、读者要慢慢发现的：

1. **祖父的"没死过"** —— 他被深渊暂时"保留"，但不是完全死亡；卷二中可见"残念"，卷三本体归来
2. **风行舟真正的动机** —— 他的弟弟被一次引渡失败的事故害死，他**不是为理念，是为复仇**；卷三揭示后读者可能动摇立场
3. **老许的真实身份** —— 他是**上一代持灯公会长老**，主动退隐成守墓人，避世却也是主角未来的一种可能
4. **林雾父母的真相** —— 他们不是"牺牲" —— 其中一位是被**暗风会策反**的；卷二末揭
5. **灯的来源** —— 最原始的灯其实来自深渊（一个**悖论**：持灯人用的工具来自他们对抗的地方）
6. **陈烛血脉里的"长明特质"** —— 祖父为了让陈烛能扛住未来，**提前将自己一部分力量烙入主角血脉**

## 写作节奏建议（执行层）

### 单章配方
```
开头（10-20%）：上一章钩子的延续 / 新场景铺设
中段（50-60%）：任务推进 / 异常对话 / 引渡核心段
尾段（20-25%）：解决 + 短暂喘息
结尾（5-10%）：下一章钩子（冲突钩 / 悬念钩 / 发现钩）
```

### 每 10 章做一次检查
- 甜区占比够不够？（目标 70%+）
- 每章都有钩子？
- 金手指有没有推进？
- 长线伏笔有没有埋？

### 每卷收尾前
- 三个钩子要清晰：本卷留的、跨卷留的、整本留的
- 主角成长有没有可见变化？
- 有没有至少 1 个角色弧有进展？

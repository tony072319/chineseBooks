## 为什么选这个组合？

### 1. 用户偏好信号强

书单里上传的书里，同类作品占比最高：

| 书 | 作者 | 备注 |
|----|------|------|
| 从红月开始 | 黑山老鬼 | 都市克苏鲁标杆 |
| 夜的命名术 | 会说话的肘子 | 都市神秘 + 命名系统 |
| 我有一座冒险屋 | 我会修空调 | 都市恐怖经营 |
| 最后一个道士 | 夏忆 | 民俗 + 都市异能 |
| 惊悚乐园 | 三天两觉 | 无限流恐怖 |
| 诡秘之主 | 爱潜水的乌贼 | 克苏鲁神秘学（非都市但同根） |
| 异常生物见闻录 | 远瞳 | 都市奇幻 |

用户传了 **会说话的肘子** 3 本（夜的命名术 / 第一序列 / 大王饶命），作者风格明显：**氛围感 + 反转 + 节奏**。
用户品味线明确：**不爱纯血玄幻升级流，爱都市神秘/悬疑氛围流**。

### 2. 番茄 2026 市场定位

| 赛道 | 竞争度 | 新人机会 | 代表作 |
|------|-------|---------|--------|
| 玄幻升级流 | 🔴 极度内卷 | 低 | 斗破苍穹（12 年前） |
| 都市神豪/系统 | 🟡 卷 | 中 | 天道图书馆 |
| 现代神话（斩神同类） | 🟡 刚起 | 中 | 我在精神病院学斩神 |
| **都市克苏鲁/神秘** | 🟢 相对蓝海 | **高** | 从红月开始、夜的命名术 |
| 无限流悬疑 | 🟡 难写但蓝海 | 中（门槛高） | 十日终焉 |

**都市克苏鲁**是**竞争相对少 + 风格对位用户 + 番茄读者有接受度**的交集。

### 3. 新人友好度

| 维度 | 评分 |
|------|-----|
| 世界观搭建成本 | ⭐⭐⭐⭐（现代都市为底，省去大量设定功夫） |
| 章节节奏难度 | ⭐⭐⭐（氛围要求高，但比无限流推理容易） |
| 续写稳定性 | ⭐⭐⭐⭐（单元剧模式，一个事件 3-5 章，不容易崩） |
| 发挥空间 | ⭐⭐⭐⭐⭐（神秘主义 = 可以一直开新脑洞） |

### 4. 金手指：特殊身份 / 背景 的优势

vs 系统流：
- 不用写机械的"任务/奖励"面板
- 身份可以**分层揭示**（读者追更动力 = "下一层真相是什么"）
- 金手指是"血脉+物品+知识+组织"的组合，层次更丰富

vs 系统流的对比：
| 维度 | 系统流 | 特殊身份流 |
|------|-------|-----------|
| 读者追更钩子 | "下次签到给什么" | "主角到底是谁" |
| 爽点节奏 | 每章一爽 | 每卷一爆 |
| 世界观承载 | 弱 | 强 |
| 新人写崩风险 | 低 | 中（需节制揭露节奏） |

## 差异化定位（不踩前辈的脚印）

| 书 | 主打 | 我们避开 |
|----|------|---------|
| 从红月开始 | 血淋淋的红月规则 + 警察体系 | 不走"赤裸暴力 + 警察"路线 |
| 夜的命名术 | 命名即规则 + 校园 | 不用"命名" 机制 |
| 诡秘之主 | 蒸汽朋克 + 穿越 + 22 条途径 | 不穿越，背景是**现代中国** |
| 斩神 | 神话 IP 联动 + 战斗爽 | 不做 IP 联动，不走战斗向 |
| 最后一个道士 | 民俗驱邪 + 师承 | 不做"道士"传承 |
| 我有一座冒险屋 | 恐怖经营流 + 店铺 | 不做"经营一个地方"的流派 |

**我们的差异化标签**：
1. **现代中国都市** 底色（不穿越、不架空城市）
2. **温情悬疑** 基调（不走纯恐怖 / 纯血腥）
3. **单元剧 + 长线身份揭示** 结构（番茄单元剧 + 起点长线双兼顾）
4. **都市神秘职业** 为切入（类似《持灯人》这种读者没见过的角色类型）

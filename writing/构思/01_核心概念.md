## 世界观速写（120 字）

现代都市。白天和所有人熟悉的一样：地铁、外卖、996。
夜晚，在城市的"阴影层"，有一些不属于这里的**异常存在**——没来得及走的、迷路的、被遗忘的。
它们大多不作恶，只是**迷途**。

有一个古老职业叫"**持灯人**"，几千年传承，在现代只剩极少数。持灯人手持一盏特殊的**灯**，能照见阴影层，能和异常存在对话，能给它们**引路**——送它们去它们该去的地方。

对立面是"**吹灯人**"——认为异常是污秽，主张把它们全部抹除。两派千年纷争。

## 主角 · 陈烛

- 22 岁，大学刚毕业在准备考研的"半废青"
- 从小父母在外地，是祖父带大的
- 祖父在开篇第一章去世，留下一座老宅、一盏油灯、一本笔记
- 直到这一刻他才知道：祖父是最后一代"老持灯人"，而他**天生就是持灯人的血脉后继**
- 性格：冷静、好奇心重、有点社恐、认死理

## 金手指（「特殊身份」的具体展开）

**1. 灯** —— "**祖父留下的长明灯**"
- 外表像一盏普通旧油灯，没油也能点燃
- 点燃时能照见阴影层的异常
- 随主角升级而"变亮"：初始只照 3 米 → 后来照亮整条街 → 最终照亮整座城
- 本身有秘密（祖父为什么能留下"长明灯"？这是第三卷的坑）

**2. 笔记** —— "**持灯人笔记**"
- 祖父一生处理过的异常案例都写在里面
- 翻开时会自动浮现**下一个任务**（时间 + 地点 + 提示）
- 关键对话会自动记录下来，便于主角复盘
- 主角自己写的心得也会被笔记吸收（长线伏笔源头）

**3. 身份** —— "**持灯人血脉**"
- 血脉激活后，主角能"看见"阴影层
- 能听懂异常存在的语言（不是中文）
- 身体比常人稍强（但打不过厉害的异常）

**4. 祖辈经验** —— "**传承梦境**"
- 关键时刻祖父会出现在梦里，点拨主角
- 不是万能 —— 祖父也有祖父不知道的事
- 到第二卷才会揭示"祖父到底是失踪还是死了"

## 力量阶梯（持灯人五境）

| 境界 | 标志 | 任务类型 |
|------|------|---------|
| **学徒** | 能点亮灯，看见阴影层 | 处理"游魂 / 灯笼魂 / 残影"等简单异常 |
| **持灯人** | 灯火稳定，可与异常对话 | 处理"执念深重的异常"，开始接组织任务 |
| **掌灯人** | 可以引渡"强力异常"，灯变成琉璃灯 | 面对"吹灯人"的试探，处理跨城事件 |
| **引渡者** | 能追踪阴影层深处 | 介入"古老事件"，接近真相 |
| **长明** | 灯永不熄灭，主角介入一切异常 | 祖父之上的境界，只有最后一代持灯人才有 |

每升一境，灯本身会有明显变化（油灯 → 风灯 → 琉璃灯 → 引路灯 → 长明灯）。

## 黄金三章（开局 8000-9000 字）

### 第 1 章 · 祖父的葬礼
- **前 300 字**：葬礼现场，秋雨。陈烛站在祖父墓前。
- **中段**：远亲陆续离去，一个拄拐杖的陌生老者走过来，说："老陈终于走完了这一生……灯，准备好了吗？" 陈烛莫名其妙，老者笑了笑走了。
- **结尾**：葬礼后整理祖父遗物，发现一盏古朴油灯 + 一本黑皮笔记。笔记第一页只有一行字：
  > "今晚 22:00，东大街 37 号灯柱下。"
- **钩子**：陈烛皱眉。这是今晚的时间、地点——但什么"任务"？

### 第 2 章 · 第一盏灯
- **前段**：陈烛出于好奇按笔记指示去东大街。
- **中段**：在 37 号灯柱下，他看见一个挂在灯柱顶端的**旧纸灯笼**——别人都看不见。他试着点燃祖父的油灯。
- **转折**：油灯亮起的瞬间，他看见灯笼里蜷缩着一个看不清形状的东西，正在无声地哭。
- **操作**：笔记自动翻到第二页，浮现出**引渡手法**。陈烛按指引操作，灯笼里的"东西"化作一缕光飘向夜空，消失。
- **钩子**：刚处理完，笔记第三页缓缓浮现：
  > "任务 002：明晚 23:15，第三实验小学后巷。注意——带够油。"

### 第 3 章 · 不速之客
- **前段**：第二天白天，陈烛整理思绪，试图理解昨晚发生的事。
- **事件**：门铃响。一个约莫二十七八岁的女人站在门外，自称**林雾**，是"持灯公会"的联系员。
- **冲突**：林雾要陈烛接手祖父留下的"业务"——"你爷爷有三十六件未完成的任务，都在你笔记里。"
- **关键信息**：林雾临走前，在门口停了一下，转身说：
  > "还有一件事。你爷爷失踪那天，身上那盏灯——**熄了**。而灯，只会熄一次。"
- **钩子**：陈烛愣住。笔记自己翻开到最后一页，写着：
  > "当灯再次熄灭，持灯人……"
  > 后面的字，**被烧焦了**，看不清楚。

## 为什么是这个开局？

照《08_开头三章模板.md》的黄金三章范式自查：

- [x] 第 1 章 500 字内：主角身份、场景、核心矛盾（祖父死 + 神秘老者 + 任务纸条）都到位
- [x] 第 2 章：金手指首次实战（灯 + 笔记 + 引渡）
- [x] 第 3 章：更大势力登场（公会），身份初步揭露
- [x] 每章有明确钩子（未完成任务、神秘信息、烧焦的文字）
- [x] 信息分层：读者第 1 章好奇，第 2 章理解规则，第 3 章对更大的世界产生渴望

## 节奏规划（框架）

- **单元剧**：每个"异常事件"占 **3-5 章**（100 个小任务 = 300-500 章空间）
- **大卷**：每卷 30-50 章，卷末解锁一个"祖父真相 + 持灯人世界观大片段"
- **总字数目标**：首作目标 **150-200 万字完本**

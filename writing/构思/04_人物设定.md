# 04 · 人物设定

## 主角

### 陈烛

| 项 | 内容 |
|---|------|
| 年龄 | 22 岁 |
| 身份 | 大学刚毕业，考研二战失败，暂居祖父老宅，无正式工作 |
| 出生地 | 故事发生地「江城」本地人 |
| 家庭 | 父母在外地做生意，从小主要由祖父陈守夜带大 |
| 外貌 | 瘦高、皮肤偏白、眉目清秀，不算帅但有点书生气 |
| 性格 | 冷静、好奇心强、有点社恐、认死理、对重要的人很守护 |
| 特长 | 从小看祖父的旧书杂记，对民俗/古文字/老物件有好感 |
| 短板 | 不擅长打架、不擅长社交、容易拖延 |
| 口头禅 | "嗯。"（说话特别省字） |
| 座右铭（成长中） | "把路走完，把灯点亮。" |

### 陈烛的核心冲突
- **表层**：失业、考研失败、人生没方向
- **中层**：意外继承持灯人身份，面对异常世界的震撼
- **深层**（卷二后浮现）：祖父到底怎么了？我要不要走他走过的路？

### 成长弧（三卷）
- **卷一**：从懵懂新人到勉强能独立处理小任务的"学徒持灯人"
- **卷二**：从"完成任务"到"理解身份" —— 开始有自己对"引渡"的思考
- **卷三**：从"继承者"到"自己的路" —— 做出不同于祖父的选择

### 避免 OOC（人物崩坏）的红线
- [ ] 不能突然变话痨
- [ ] 不能突然变打架狂魔
- [ ] 不能在重大决定前不犹豫
- [ ] 不能对陌生异常马上共情（是渐变过程）

## 重要配角

### 陈守夜（祖父）· 亡者 / 传承者

| 项 | 内容 |
|---|------|
| 生卒 | 约 1945 - 故事开始 |
| 身份 | 持灯人，**准长明境**，最后一代"老持灯人" |
| 与主角关系 | 祖父，主角从 3 岁起主要由他带大 |
| 出场方式 | 第 1 章葬礼（遗物），第 5 章起以"梦境"回归 |
| 性格 | 沉默寡言、严肃但慈爱、有一种"守夜人"的孤独气质 |
| 秘密层级 | 卷一：他是持灯人 / 卷二：他失踪的真相 / 卷三：他真正的身份 |

**祖父的复杂之处**（写作时要记住）：
- 他不是完美长辈 —— 年轻时也犯过错
- 他没有告诉主角一切 —— 有他的考量，也有他的私心
- 他的"失踪"背后是一个主角到卷二末才能接受的真相

---

### 林雾（女主候选 / 搭档）

| 项 | 内容 |
|---|------|
| 年龄 | 26 岁 |
| 身份 | 持灯公会江城分会的**联络员**（一线外勤），**掌灯人境** |
| 外貌 | 中长直发，常穿风衣 + 牛仔裤；眼睛一边浅一边深（异瞳） |
| 性格 | 外冷内热，专业主义，说话干脆，偶尔开"黑色幽默"玩笑 |
| 家庭 | 持灯世家林氏，父母双亡（牺牲于"30 年前大事件"） |
| 特点 | **能使用两盏灯**（自己的 + 死去父亲留的），罕见 |
| 与主角的关系 | 先**冷酷导师**，后**战友**，卷三可能**恋人**（慢热） |

### 林雾是女主还是搭档？
- 前 30 章当**搭档 + 冷酷前辈**处理
- 情感线不宜早放，番茄读者看男频对硬塞女主情节不耐
- 卷二起有"**互相动心但不说破**"的暧昧
- 卷三末期才有清晰恋爱线

---

### 老许（亦师亦友的隐居者）

| 项 | 内容 |
|---|------|
| 身份 | 开局葬礼上那个**拄拐杖的老者**，其实是"**守墓人**"（独行持灯人） |
| 年龄 | 看不出，说他 60 岁也信，说他 100 岁也信 |
| 外貌 | 白胡子、拄一根"仿杖其实是灯杖"的拐杖 |
| 性格 | 爱喝酒、爱说俏皮话、表面糊涂实则洞察一切 |
| 关系 | 祖父的老朋友 / 陈烛的**非官方师父** |
| 他的"引渡业务" | 专守江城城南一座**废弃博物馆** |

**老许的作用**：
- 补位 —— 主角需要直接对话的前辈时，祖父不能说的话他来说
- 调味 —— 温馨 + 搞笑的配角，缓解神秘氛围的紧绷
- 伏笔 —— 老许知道比自己透露的多得多

---

### 沈栖梧（陈烛的大学室友）

| 项 | 内容 |
|---|------|
| 年龄 | 23 岁 |
| 身份 | 普通人，游戏公司美术实习生 |
| 与主角关系 | 大学同宿舍 4 年，**没血缘但当亲兄弟**的好友 |
| 性格 | 开朗、话多、脑回路清奇、嘴毒 |
| 作用 | **普通人视角的锚点** —— 让主角不要彻底陷入阴影层 |
| 剧情参与 | 前 30 章不知情，卷一末**因为一次意外撞见** |

**沈栖梧重要的原因**：
- 让主角"下班后还有人一起打游戏吃宵夜"—— 温情底色
- 后续揭晓他身上也有**微弱的"共感体质"**（非血脉，偶然接触阴影层），成为主角**外援**
- 男频读者需要"兄弟"角色，不是所有感情都是暧昧

## 反派

### 风行舟（第一反派，吹灯人代表）

| 项 | 内容 |
|---|------|
| 年龄 | 34 岁 |
| 身份 | **暗风会**的中层核心，吹灯人"**新派**"的代表 |
| 外貌 | 高、瘦、书卷气，总穿黑色风衣，手持一支**墨色长烟**（实际是特制黑烛） |
| 性格 | 冷静、礼貌、**真诚相信自己在拯救世界** |
| 武器 | 黑烛（吹灭异常 + 吹灭持灯人的灯） |
| 首次出场 | 第 15 章（吹灭主角正在引渡的一只执念体） |
| 和主角关系 | 对手 + 思想上的镜像 |

**风行舟的"可怕"**：
- 不是坏人 —— 他救过普通人、救过孩子、他是有信念的
- 他觉得**持灯人太软弱**，异常该被清除
- 他会用道理和数据说服主角："你看，你救的那个灯笼魂，昨晚吓哭了一个 5 岁小女孩"
- **读者和主角都会一度怀疑：是不是他说的对？**

### 风行舟背后的暗风会
- 卷一只露一角（风行舟 + 2-3 个手下）
- 卷二整个组织浮现
- 卷三揭示他们的真正目的（比主角想象的更复杂）

## 其他重要配角（简写）

### 苏奶奶
- 陈烛祖父老宅的邻居，80 岁
- 知道祖父"不一般"但从不追问
- 主角的**生活后援**（送早饭、问候）
- 温情元素

### 阿骨（持灯公会"分析员"）
- 25 岁女孩，戴眼镜，宅
- 持灯公会的档案管理员
- 给主角提供"历史案例"支持
- 搞笑 + 资料库

### 周队（某派出所民警）
- 40 岁，老派出所所长
- 和持灯公会有秘密合作协议
- **普通世界的协调人** —— 帮主角处理"异常事件的表层善后"（报警记录、伤者家属、封锁现场）

### 裴秉林（陈烛的父亲，远隔）
- 生意人，多年在外
- 对主角既关心又疏远
- 卷二揭示：他**故意远离**老宅，因为他知道老宅的秘密
- 复杂的父子关系（不是狗血，是代际疏离的典型）

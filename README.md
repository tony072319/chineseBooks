# 中文网文写作项目 · chineseBooks

> **目标**：系统性研究中文网文（网络小说）的创作规律，最终在番茄小说平台上写出并发表一部原创作品。
>
> **关键词**：不是文学、是商品；不是艺术、是服务读者；不是一本小说、是一款连载产品。

---

## 这个仓库是什么？

这是一个个人写作学习工程，按照「研究 → 语料采集 → 模式分析 → 构思 → 写作 → 发布」六个阶段推进。

当前处于 **Phase 1**：写研究手册，把网文的底层逻辑搞清楚再动手写。

## 工程原则

1. **合规优先**
   - 后续 Phase 会从盗版聚合站抓取小说原文，**仅用于本地学习分析**
   - `corpus/raw/` 已在 `.gitignore` 中排除，**正文绝不提交到 git**
   - 抓取请求保持每请求 ≥ 2 秒间隔，不并发，不拖垮对方服务器

2. **原创性优先**
   - 番茄小说有严格原创检测，纯 AI 生成作品永久封禁
   - 本项目学习的是**套路、结构、节奏**，不是搬运句子
   - 写作阶段会自查句式相似度

3. **数据驱动**
   - 爆款研究不凭感觉、要看指标：在读人数、完结字数、追读率、榜单名次
   - 自己写作阶段同样看数据：首日阅读量、留存、追读、完读率

4. **小步快跑**
   - 手册 → 爬虫 → 分析 → 选型 → 写作，每个阶段结束都要回顾
   - 宁可首作扑街，也要跑完一整本书拿到数据反馈

## 给自己的期望管理

- **"读 100-1000 本"** 是指 **AI 辅助扫读 + 人工精读少数标杆**，不是逐字读
- **首部作品大概率不火**，目标是"保质保量、跑完一本、拿到数据"
- 网文作者生存压力大，日更 4000-6000 字是常态。认真评估你自己每天能投入多少时间，再决定是否进入 Phase 5

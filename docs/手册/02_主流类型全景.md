# 02 · 主流类型全景

## 核心结论

1. 网文分类有两套视角：**大类**（玄幻/都市/历史/科幻/修真/仙侠/悬疑/游戏）和 **标签/流派**（系统流/无限流/签到流/凡人流/重生流/赘婿流…）。新人选型要选"大类 + 2-3 个标签"的组合。
2. **玄幻 + 系统流** 是番茄男频最稳的组合，门槛低、读者多、套路成熟。
3. **无限流 / 悬疑** 近两年靠《十日终焉》等作品起量，门槛高但竞争相对小。
4. **都市脑洞流** 是番茄特色，结构最轻，适合练手。
5. 每种类型都有明确的 **读者预期**，选错了写什么都救不回来。

## 一、玄幻（含升级流 / 系统流）

### 1.1 玄幻是什么
作者原创世界观，融合修炼、武道、异能、东方神话等元素。力量等级通常是 XX 者 → XX 师 → XX 王 → XX 圣 → XX 帝 的阶梯。

### 1.2 典型套路
- **废柴 / 平凡 → 金手指觉醒 → 一路升级碾压**
- **家族 / 宗门被灭 → 主角复仇 → 查真相**
- **穿越到异世 → 用前世知识开挂**

### 1.3 金手指选择
系统（任务、签到、商城）、炼丹、炼器、上古传承、神秘血脉、逆天功法

### 1.4 代表作拆解要点
- 《斗破苍穹》：见 [`04_爆款解剖-斗破苍穹.md`](04_爆款解剖-斗破苍穹.md)
- 《遮天》：辰东，世界观宏大、文笔有韵味
- 《完美世界》《圣墟》：世界观套娃、坑多

### 1.5 适合写吗？
**适合**。番茄男频玄幻神话类长期霸榜，模板成熟。但卷得狠，要有明显差异化金手指或人设。

---

## 二、仙侠 / 修真

### 2.1 区别
- **仙侠**：偏东方神话、重情义、有道德底色（古典仙侠）
- **修真**：纯架空、升级体系数值化，侧重过程（现代修真）

### 2.2 经典升级体系
`练气 → 筑基 → 金丹 → 元婴 → 化神 → 合体 → 大乘 → 渡劫`

这一套由《缥缈之旅》奠定，后来所有修真文几乎都照用或微调。

### 2.3 套路
- **凡人流**：主角无大机缘、靠谨慎稳健一步步活下来（《凡人修仙传》）
- **仙葫 / 神兵 + 前世记忆**
- **宗门体系**：外门弟子 → 内门 → 长老 → 掌门

### 2.4 代表作
- 《凡人修仙传》：忘语，修真鼻祖级
- 《牧神记》：宅猪，见 [`05_爆款解剖-牧神记.md`](05_爆款解剖-牧神记.md)
- 《择日飞升》：宅猪新作，内卷式修真

### 2.5 适合写吗？
需要对境界体系有深入理解，设定、伏笔密度高。**新人慎入**，除非你是这类型铁粉。

---

## 三、都市

### 3.1 子类型极多
- **神豪流**：主角突然暴富（红包、签到、诅咒继承）
- **赘婿 / 兵王 / 战神**：隐藏身份扮猪吃老虎
- **娱乐圈 / 直播**：主角做影视、游戏、直播走红
- **都市修真 / 异能**：现代背景下有神秘力量
- **都市脑洞**：番茄特色，《万族之劫》《我的两千四百年日记》

### 3.2 套路关键词
"扮猪吃老虎"、"打脸"、"装逼"、"回城"、"隐藏身份"、"主角在底层"

### 3.3 代表作
- 《我的1978小农庄》：年代 + 种田 + 都市
- 《诸天影视开局萧峰》：影视诸天流
- 《我的两千四百年日记》：脑洞流代表

### 3.4 适合写吗？
**非常适合**。结构轻、世界观几乎零成本、读者面最广。缺点是套路最卷，需要差异化 hook。

---

## 四、系统流（横跨玄幻/都市/修真）

### 4.1 什么是系统
给主角一个"外挂助手"——会签到、会发任务、会给奖励。读者能清晰看到升级路径。

### 4.2 子类型
- **签到流**：每日签到获得奖励（灵气、武功、金钱）
- **任务流**：任务清单模式，完成给奖励
- **养成流**：培养弟子、家族、国家
- **文抄流**：穿越后默写前世名作赚名声（《诡秘之主》部分套用）

### 4.3 优势
- 读者门槛极低，告诉他"主角今天签到抽到了什么"就有人追
- 章节结构固定：开场→签到/抽奖→获得奖励→使用奖励→装逼打脸→钩子

### 4.4 劣势
- 套路化严重，同质化严重
- 读者对"水"的忍耐度低，不能每章都只签到不推进主线

### 4.5 适合写吗？
**非常适合新手**。结构模板极稳，章节容易拆分。

---

## 五、无限流 / 悬疑

### 5.1 什么是无限流
主角反复进入不同的任务世界或游戏副本，每个小世界都有规则、都要活下来。

### 5.2 代表作
- 《无限恐怖》：无限流开山
- 《十日终焉》：见 [`03_爆款解剖-十日终焉.md`](03_爆款解剖-十日终焉.md)
- 《诡舍》：恐怖 + 无限流
- 《死亡万花筒》（女频）

### 5.3 套路要素
- **规则系统**（进入副本的条件、存活条件、奖励机制）
- **多世界观**（每个副本可以是恐怖片、宫斗、科幻、古代）
- **悬疑揭秘**（为什么主角被拉进来？规则背后是谁？）

### 5.4 优势
- 可以复用各种现成 IP 的设定元素（不抄袭的前提下）
- 每个副本结束自带节奏感
- 悬疑推动读者追更

### 5.5 劣势
- 对逻辑严密度要求极高
- 作者需要同时构思多个世界观
- **新人慎入**，写崩风险大

---

## 六、重生 / 穿越

### 6.1 核心
主角带着前世记忆 / 现代知识到新时代，用信息差碾压。

### 6.2 子类型
- **重生回年少**：都市金融、娱乐圈、平凡人逆袭
- **穿越古代**：商战、宫斗、种田、架空历史
- **穿越异界**：结合玄幻/修真
- **位面穿梭**：在多个世界间来回（准无限流）

### 6.3 代表作
- 《回到过去做财阀》
- 《宋时归》
- 《我的两千四百年日记》（重生两千四百次的日记流）

### 6.4 适合写吗？
模板成熟，新人友好，但写都市重生要对你"重生到的年代"做足功课。

---

## 七、科幻 / 末世 / 克苏鲁

### 7.1 近年趋势
- **克苏鲁/神秘学** 因《诡秘之主》火起来
- **末世** 长期有固定盘口（《末日乐园》）
- **赛博朋克 / 星际** 门槛高，头部集中

### 7.2 代表作
- 《诡秘之主》：爱潜水的乌贼，蒸汽朋克 + 克苏鲁 + 神秘学
- 《深海余烬》：远瞳，末日 + 神秘
- 《学霸的黑科技系统》：科技流

### 7.3 适合写吗？
世界观成本高、读者挑剔。**不推荐新人入**。

---

## 八、历史 / 军事

### 8.1 特点
需要大量考据，错一个年代、一个官职就被喷。真爱粉才写。

### 8.2 代表作
- 《奋斗在五代末》
- 《宰执天下》

### 8.3 适合写吗？
**不推荐新人**。

---

## 九、游戏 / 电竞

### 9.1 特点
- **全息 / 网游**：带入游戏世界
- **电竞**：现实背景职业选手成长线

### 9.2 代表作
- 《全职高手》
- 《网游之近战法师》

### 9.3 适合写吗？
要懂游戏、要能把"打游戏"写得让不打游戏的人也看得进去。门槛中等。

---

## 十、女频（简介，本项目暂不主攻）

- **古言**：宫斗、宅斗、种田、穿越古代
- **现言**：霸总、娱乐圈、甜宠、豪门
- **悬疑**：女性向无限流、灵异
- **耽美**（站点敏感，番茄不允许）

女频读者对 **情绪、人设、感情戏** 的敏感度远高于男频。

---

## 给新人作者的启示

1. **先选"大类 + 2 个标签"**。不要一上来就想写跨多个类型的作品。
2. **推荐组合**（新人友好度高到低）：
   - 玄幻 + 系统流 + 升级流 ⭐⭐⭐⭐⭐
   - 都市 + 系统流 + 签到流 ⭐⭐⭐⭐⭐
   - 玄幻 + 洪荒 / 东方神话 ⭐⭐⭐⭐
   - 都市 + 赘婿 / 战神 ⭐⭐⭐⭐
   - 都市 + 脑洞流 ⭐⭐⭐⭐
3. **慎选**：无限流、修真、科幻、历史。不是不能写，是新人写不稳。
4. **绝对不要**：试图把 3 个及以上的类型融合，除非你已经写过 3 本以上作品。

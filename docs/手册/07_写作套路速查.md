# 07 · 写作套路速查

## 核心结论

1. **套路不是贬义词**：它是读者心理预期和作者表达之间的成熟语言——新人先学会说这门语言，再谈创新。
2. **金手指是开局第一定义**：决定了全书的类型、节奏、爽感来源。
3. **爽点是燃料**：小爽点 3000 字一次，大爽点 3 万字一次，否则读者流失。
4. **钩子是缰绳**：每章末留钩，每卷末留大钩，读者跑不掉。
5. **反转和伏笔要预先布局**：不是想到哪写到哪，好的反转需要至少 5 章前的铺垫。

---

## 一、金手指设计

### 1.1 常见金手指类型

| 类型 | 典型 | 优点 | 缺点 |
|------|------|------|------|
| 系统（面板/任务/商城/签到） | 《神豪从红包开始》 | 读者最熟悉、结构最稳 | 过于套路 |
| 穿越/重生（前世记忆） | 《回到过去做财阀》 | 信息差天然 | 需要对穿越时代做功课 |
| 师父/前辈传承（戒指老爷爷） | 《斗破苍穹》 | 有情感维度 | 容易写成工具人 |
| 血脉 / 天赋觉醒 | 《遮天》 | 给主角"特别" | 合理性容易崩 |
| 特殊物品（神兵、仙葫、宝鉴） | 《仙葫》 | 物品本身有故事 | 限制主角成长弹性 |
| 身体改造（魔瞳、第二灵魂、变异） | 《凡人修仙传》 | 独特 | 要想清楚副作用 |
| 文抄 / 抄袭（前世文娱） | 《这个文娱不太正》 | 爽点密集 | 被指抄袭嫌疑 |
| 模拟器（人生/战斗/经营） | 《人生模拟器》 | 新颖 | 已被写烂 |

### 1.2 金手指设计三原则
1. **要"可观测"**：读者能清晰看到主角得到了什么（签到面板、戒指显字、技能列表）
2. **要"有限制"**：纯无敌金手指没有张力，必须有代价或冷却或条件
3. **要"可成长"**：金手指本身也要升级（系统升级、老爷爷恢复、血脉觉醒更深层）

### 1.3 金手指出现时机
- **最晚第 2 章**（黄金三章的核心要求）
- 出现前主角必须先**陷入足够的困境**
- 最好有"偶然中的必然"——读者觉得合理

## 二、爽点设计

### 2.1 爽点四大类型
1. **打脸爽**：之前看不起主角的人被主角碾压（核心！）
2. **发现爽**：主角获得稀有物/技能/真相，读者替他兴奋
3. **碾压爽**：弱势变强势，小人物打倒大势力
4. **拯救爽**：主角救了重要角色（家人、恋人、朋友、百姓）

### 2.2 爽点密度
- 微爽点：**每 3000 字一次**（一章一个小进展、小胜利）
- 中爽点：**每 3-5 万字一次**（击败一个较大的对手）
- 大爽点：**每 30-50 万字一次**（推翻一个势力、揭开一个真相、进入新阶段）

### 2.3 爽点的"铺垫-释放"模型
```
铺垫（压抑）→ 释放（爆发）
```
- 铺垫越狠，释放越爽
- 铺垫时读者情绪要被调动到"愤怒 / 担忧 / 同情"
- 释放时让读者"哈哈哈这帮傻子被打脸了"

### 2.4 反面：爽点误区
- ❌ 无铺垫的碾压（读者无感）
- ❌ 过于夸张的装逼（用力过猛显尴尬）
- ❌ 一章塞三个爽点（饱和麻木）
- ❌ 只有爽点没有伏笔和推进（读者审美疲劳）

## 三、钩子 / 悬念设计

### 3.1 钩子的五种类型
1. **冲突钩**：敌人出现、打斗开始，打到一半结束
2. **悬念钩**：某人某事留下疑问（"他为什么这么说"）
3. **发现钩**：主角发现奇怪的东西，但还没查明
4. **反转钩**：某个看似确定的事被推翻，新答案还没给
5. **危机钩**：主角陷入危险，下一章看怎么脱身

### 3.2 钩子的位置
- **章末**：最重要，必留
- **章首**：最好有"回顾/情境"帮上章没看完的读者续上
- **卷末**：大钩，让读者等下一卷

### 3.3 钩子设计技巧
- 最后一句话必须**有信息量 + 未完成感**
- 不要用"预知后事如何，请看下章" 这种硬废话
- 留钩但不要玩谜语（读者看不懂就走）

### 3.4 好钩子的例子（示意）
> 萧炎刚要转身，身后传来一个冰冷的声音：
> "三年了，当年被你打伤的人，我们是不是该聊聊？"
> （冲突钩 + 悬念钩：此人是谁？）

## 四、反转 / 伏笔

### 4.1 反转的层级
- **小反转**：单个情节内的反转（本以为是敌人，其实是盟友）
- **中反转**：多章情节的反转（本以为是陷害，其实是保护）
- **大反转**：世界观 / 身世的反转（主角其实是…）

### 4.2 反转三原则
1. **预埋证据**：反转前必须有 5 章以上的"异常信号"（读者重读时恍然大悟）
2. **合理可信**：反转不是"我编不下去就推翻"，必须有内在逻辑
3. **情感有张力**：好的反转能带来情绪冲击，不只是信息惊喜

### 4.3 伏笔的"不声不响"
- 好的伏笔读者第一次读时**不会注意**
- 反转揭开时读者**自动回忆起**
- 不要用"值得注意的是……"这种强提示

## 五、节奏曲线

### 5.1 一章的节奏
```
开头（情境续上）→ 中段（推进 / 冲突）→ 结尾（爽点 + 钩子）
    20%              60%                    20%
```

### 5.2 一卷的节奏
```
开卷引入 → 铺陈压抑 → 转折 → 爽点释放 → 高潮 → 收尾铺下卷
   5%        30%       10%      30%       15%      10%
```

### 5.3 一本书的节奏
```
起始（小格局）→ 扩张（中格局）→ 高潮（大格局）→ 终章
   30%           50%              15%            5%
```

### 5.4 节奏"呼吸感"
- 不能一直紧张（读者会累）
- 不能一直轻松（读者会走）
- 紧张后必有喘息（日常、师门互动、幽默桥段）

## 六、人设套路

### 6.1 主角必备属性
1. **初始伤害**（退婚、灭族、背叛、被误会）
2. **动机清晰**（复仇、证明自己、保护某人、寻找真相）
3. **独有能力**（金手指）
4. **性格爆点**（在某种情况下必然爆发）
5. **人际资源**（至少 2 个可靠战友、1 个导师）

### 6.2 主角性格类型
- **冷静隐忍型**（秦牧、齐夏）
- **热血耿直型**（萧炎、叶凡）
- **腹黑心机型**（少数，慎用）
- **话痨皮贱型**（需要真性情底色支撑）

### 6.3 反派设计
- **小反派**：明显讨人嫌，打脸用
- **中反派**：有自己的故事，但立场对立
- **终极反派**：最好有"可理解但不赞同"的动机
- 忌讳：反派全员弱智、每个都是"你竟然敢打我"

### 6.4 女主 / 配角
- 不要写成功能性花瓶
- 每个重要配角都要有自己的**一个故事线**
- 配角可以救主角、可以短期超越主角（高光时刻）

---

## 七、"装逼"与"打脸"的基本章法

### 7.1 经典打脸流程
1. 场景铺设（重要场合：拍卖会、宗门大比、家族聚会）
2. 反派嚣张（嘲笑、侮辱、挑衅主角或主角亲友）
3. 主角低调示弱
4. 反派得意
5. 主角亮招（金手指、底牌、身份）
6. 反派震惊 + 装不下去
7. 主角顺手碾压
8. 围观群众"卧槽卧槽卧槽"
9. 收尾留钩

### 7.2 装逼的度
- 要**隐藏-反差**不要**直接耍**
- 主角装之前要有"被逼到角落"的铺垫
- 打脸完要快速收场，不要回头反复品评

---

## 八、高频"梗"与"套路名"速查

- **扮猪吃老虎**：主角故意低调，暴爆发时反差
- **人在家中坐、锅从天上来**：主角无辜被卷入
- **此人身份不简单**：其他角色议论主角
- **回家看爷爷**：主角身份揭晓的经典场景
- **老爷爷的鸽子**：金手指（尤其是戒指老爷爷）迟迟不露面
- **系统崩了/黑了/卡了**：作者没想清楚怎么写时的借口
- **高人坐下的弟子**：主角师承后的身份升级
- **我的女人你也敢动？**：保护女主的打脸触发语
- **没有人比我更懂 X**：穿越者打脸专用

---

## 给新人作者的启示

1. **金手指开篇第 2 章前到位**
2. **每章小爽点 + 章末强钩子** 是铁律
3. **铺垫-释放** 比 "直接爽" 效果好 3 倍
4. **至少预埋 3 个伏笔**，在全书不同节点收
5. **反派要可恨，但不能弱智**
6. **主角动机要简单、清晰、可持续**
7. **套路不是枷锁**：你可以**把两个套路重组**（比如"系统流 + 无限流"），但不要一上来就想颠覆

# 08 · 开头三章模板

## 核心结论

1. **开头是决定书命运的地方**。番茄首日阅读不到 400，基本就判死刑了。
2. **前 500 字 = 第一印象 = 留 / 弃的分水岭**。读者不会等你铺垫。
3. **黄金三章模板老了，但"前三章必须让读者留下"的原则永远成立**。
4. **模板可变，但必须要有：主角身份 + 核心困境 + 金手指出现 + 初次反击**。
5. 新人先学**保守型开头**，吃透节奏再尝试创新型开头。

---

## 一、前 500 字必须完成的事

这是番茄算法验证期的决战区。任何一项缺失都可能让读者划走。

- [ ] 主角**名字**出现
- [ ] 主角**身份 / 处境**交代（越具体越好）
- [ ] 主角**当前遇到的困境 / 冲突**（具体事件，不是泛泛)
- [ ] 情感**钩子**（让读者替主角感到不爽、好奇、愤怒、紧张）
- [ ] 至少一个**未解悬念**（为什么他是这样？这个人是谁？）

### ❌ 反面：前 500 字绝对不能干的事
- 大段风景描写（"天色渐暗，山风呼啸……"）
- 大段世界观介绍（"在这片大陆上，分为九州……"）
- 主角心理独白超过两段
- 任何"XX 年前……"的倒叙
- 无关路人的对话
- 作者吐槽或元叙事

---

## 二、三种经典开头模板（可直接套）

### 模板 A：低谷冲突开局（斗破苍穹式）

**结构**：
1. 主角在某个仪式 / 场合（测试、拜师、比武）
2. 现场公开失败 / 被羞辱
3. 周围人嘲讽 / 议论
4. 主角内心的屈辱和决心
5. 离场时的复仇誓言（或金手指初现）

**适用类型**：玄幻 / 修真 / 升级流

**示例开头（模板性示意，自己要重写）**：
> "萧炎，斗之气三段。"
> 测试长老冷漠的宣布回荡在测试厅中……

**第一章收尾**：告知金手指即将到来 or 身份的神秘暗示

### 模板 B：任务触发开局（系统流 / 都市流）

**结构**：
1. 主角的平凡日常（打工、落魄、被甩）
2. 一个突发事件（意外、奖励、电话、快递）
3. 系统 / 金手指激活
4. 第一次体验金手指威力
5. 章末钩子：明天的挑战

**适用类型**：都市 + 系统流、签到流、神豪流

**第一章收尾**：读者清楚地看到"明天签到能得什么"，产生追更动力。

### 模板 C：谜题悬疑开局（无限流 / 悬疑）

**结构**：
1. 主角在一个**非常规情境**中醒来 / 被带入
2. 规则被强制告知（或隐约透露）
3. 周围出现其他"玩家"
4. 第一次死亡 / 威胁事件
5. 主角开始观察 + 推理

**适用类型**：无限流、悬疑、末世、克苏鲁

**第一章收尾**：留一个规则上的大疑问（"为什么这条规则有例外？"）

## 三、第一章详细结构模板（~3000 字）

### 三幕式
```
第一幕 · 情境亮相（500-800 字）
  ├ 主角出场
  ├ 核心矛盾点出
  └ 情感基调建立

第二幕 · 冲突升级（1200-1800 字）
  ├ 矛盾具体化
  ├ 压力上升（被羞辱、陷入困境）
  ├ 主角尝试反击（失败）
  └ 陷入低谷

第三幕 · 转折钩子（500-800 字）
  ├ 主角独自面对绝境
  ├ 金手指首次闪现（或悬念升级）
  └ 章末留钩：明天会发生什么
```

### 每段落长度
- **一段不超过 3 行**（手机屏幕一屏）
- **对话占比 40-60%**（纯叙述过多，读者划)
- **动词密度高**（别老用"他觉得"、"他认为"）

---

## 四、第二章的任务

**关键词：金手指登场 + 初步使用**

结构：
1. 承接第一章末尾（主角的反应）
2. 金手指激活的具体场景
3. 读者被告知金手指的规则 / 能力
4. 主角第一次用金手指做点事（哪怕很小）
5. **章末钩子**：这个金手指的能力远不止如此

**禁止**：
- 在第 2 章继续铺垫世界观
- 让主角在第 2 章就变得超级无敌

---

## 五、第三章的任务

**关键词：第一次打脸 + 全书基调确立**

结构：
1. 主角用金手指做一件之前做不到的事
2. 之前看不起 / 欺负主角的人出现
3. 主角完成一次**小而漂亮**的反击
4. 周围人的反应（震惊 / 质疑 / 讨好）
5. 章末钩子：更大的威胁在远处（卷级别 boss 初露）

**这一章决定"类型基调"**：你是爽文、悬疑、种田、日常，要在第 3 章让读者完全明白。

## 六、模板作业模板（填空式）

### 在写开头前，**先填完这个表**，再动笔：

```
【主角基本信息】
- 名字：
- 年龄 / 身份：
- 所在场景（越具体越好）：
- 时间（白天/夜晚/节日/重要日子）：

【第一章困境】
- 主角遇到的具体事件：
- 对手是谁：
- 主角为何处于劣势：
- 事件的后果（让读者替主角担心什么）：

【金手指】
- 类型（系统 / 戒指 / 重生 / 其他）：
- 第一次露出的场景：
- 初始能力（不要太强）：
- 限制 / 代价 / 条件：

【黄金三章钩子】
- 第 1 章末钩：
- 第 2 章末钩：
- 第 3 章末钩：

【全书基调】
- 这本书的爽点来源主要是什么？
- 主角长期目标是什么？
- 同质化作品中我的差异点是什么？
```

## 七、上架前的开头"三遍检查法"

### 第一遍：**冷读测试**
- 让完全不了解你构思的人（朋友、家人）读前 3 章
- 问他们：主角是谁？他想干什么？为什么你想读下一章？
- 如果答不上来，重写

### 第二遍：**对比测试**
- 打开番茄新书榜前 10 本
- 读它们的前 3 章
- 和你的对比：开篇速度、信息密度、钩子强度
- 差距明显就重写

### 第三遍：**钩子测试**
- 单独把你每章最后 200 字拿出来
- 这些字能不能让一个陌生人想"那下一章呢？"
- 不能就重写结尾

## 八、几个开头反例（避雷）

### 反例 1：风景铺开型
> "北风卷起大漠黄沙，夕阳余晖洒向荒凉的戈壁。一个身影在风沙中艰难行走……"

**问题**：前 200 字主角没行动、没冲突、没对话。读者划走。

### 反例 2：世界观 dump 型
> "这是一个斗气横行的世界，共分九州十八域。在东州的西南角，有一座小城叫做乌兰城……"

**问题**：主角还没出场，读者已经睡着。

### 反例 3：主角独白型
> "萧炎坐在院子里发呆。他想着这些年的种种经历，想着自己从天才到废柴的转变……"

**问题**：心理独白超过 200 字 = 节奏杀手。

### 反例 4：大事件平淡开局
> "今天是宗门大比的第十场。所有弟子都聚集在演武场……"

**问题**：没有主角视角，没有情感锚点，读者不知道看谁、为什么看。

## 九、正例参考（网文史上著名开头）

- **《斗破苍穹》**：测试场面失败 + 嘲笑 + 耻辱 + 钩子（仅 400 字）
- **《我的两千四百年日记》**：一开始就亮出金手指——"重生了两千四百次"
- **《诡秘之主》**：克莱恩醒来发现自己在异世界的尸体旁（情境钩）
- **《十日终焉》**：直接进入游戏场景 + 规则告知（悬疑钩）

---

## 给新人作者的启示

1. **先做"填空表"再动笔** — 没想清楚别写
2. **前 500 字反复打磨至少 5 遍**（这是决战区）
3. **三章写完冷放 24 小时再重读** — 自己都觉得没意思就重写
4. **不要爱上自己的文字**：改是写作的一半
5. **模板先用一遍看效果**，过稿了再谈创新
6. **开头写不好就卡死**：别推进到第 20 章才意识到开头废了，重写成本太大

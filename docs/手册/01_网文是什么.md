# 01 · 网文是什么

## 核心结论

1. **网文是商品，不是作品**：它服务读者消费体验，不追求文学价值；判断标准是留存、追读、月票，不是文学史地位。
2. **网文是连载产品**：一次创作、持续更新、用章节钩子锁住读者，更像追剧、刷短视频，不像读书。
3. **网文的底层是"爽"**：读者买单的不是文笔，是代入主角获得的即时情绪满足——逆袭、打脸、升级、拯救。
4. **网文是工业化写作**：套路、金手指、黄金三章不是贬义词，是成熟的产品范式，新人可以直接使用。
5. **番茄时代的网文 = 下沉流量 + 免费阅读 + 短剧化**：对爽点密度、节奏、开篇吸引力的要求比起点时代更高。

---

## 一、网文 vs 文学：不是一回事

| 维度 | 文学小说 | 网文 |
|------|----------|------|
| 读者预期 | 思考、审美、共鸣 | 打发时间、获得爽感 |
| 阅读场景 | 桌前、深度阅读 | 地铁、睡前、刷短视频间隙 |
| 一本书长度 | 10-40 万字 | 100-500 万字起步，1000 万字不稀奇 |
| 阅读姿态 | 逐字读 | 跳读、扫读、追更 |
| 更新方式 | 出版一次 | 每日连载 2-6 千字，持续半年到两年 |
| 成败指标 | 获奖、销量、口碑 | 追更率、留存、月票、订阅 |
| 收入来源 | 版税（一次性） | 广告分成、付费订阅、IP 改编分成 |
| 作者工作状态 | 慢工出细活 | 打工人：日更、回评、看数据 |

**关键洞察**：文学是作品，讲完一个故事就结束。网文是**服务**——每天要给读者一个"明天还想来看"的理由。

## 二、网文的商业逻辑

### 2.1 平台两种模式
- **付费阅读**（起点、纵横、晋江）：读者按章付费（千字 3-5 分钱），作者靠订阅 + 全订/均订数据拿分成和奖项
- **免费阅读**（番茄、七猫、掌阅）：读者免费看，平台插广告；作者靠"听读时长分成"、千字稿费、全勤奖、活动奖

### 2.2 番茄模式的特点（重点）
- 门槛低：2 万字即可申请签约，通过率 > 60%
- 流量大：用户量 2 亿 +，日活上亿
- 算法分发：新书靠推荐池梯度晋级，**不是靠编辑审美**
- 爽点要密：免费读者留存差，开篇钩子必须狠
- 日更压力大：断更 3 天，流量断崖

### 2.3 作者的收入来源（按比例从高到低）
1. **平台稿费分成 / 千字稿费**（番茄主要是听读分成 + 保底）
2. **全勤奖**（日更达标才给，500-2000 元/月）
3. **IP 改编**（短剧、广播剧、动漫、影视——近两年番茄短剧爆发）
4. **打赏、月票奖励、榜单奖**

## 三、读者画像

### 番茄读者（下沉、男频为主）
- 地铁通勤上班族、工厂工人、学生、外卖员、宝妈
- 阅读目的是放松、逃避现实、获得情绪出口
- 对文学性、文笔修辞 **不敏感**
- 对"主角什么时候变强"、"什么时候打脸仇人"、"什么时候扮猪吃老虎" **极度敏感**
- 习惯用手机竖屏读，一屏 200 字左右，段落必须短

### 起点读者（付费、更深度）
- 愿意为内容付费的相对核心读者
- 对逻辑硬伤、人设崩塌、套路复读零容忍
- 对世界观深度、文笔细节有要求

**结论**：番茄时代写网文，对文笔要求低但对 **节奏感、爽点密度、钩子能力** 要求极高。

## 四、几个必须理解的概念

- **金手指**：主角相对常人拥有的超能力或特殊物品（系统、重生、异瞳、丹田改造、签到、穿越记忆）。**开篇就要露出**。
- **爽点**：让读者替主角爽到的情节（碾压对手、解救美人、一鸣惊人、打脸装逼、意外收获）。**最好每 3000 字一个小爽点，每 3 万字一个大爽点**。
- **钩子（悬念）**：章末留问题让读者点"下一章"。分冲突钩、悬念钩、发现钩、反转钩。
- **黄金三章**：第 1 章冲突亮相、第 2 章金手指到手、第 3 章第一次打脸。**不要教条照搬，但"前 3 章必须让读者留下"的原则永远成立**。
- **卷**：一本网文一般分 3-10 卷，每卷是一个相对独立的故事弧线，卷末通常有大高潮和新悬念。
- **完本**：故事结束。网文完本的字数一般 200 万字起步，300-500 万字常见。

## 五、误区清单（新人最容易踩的坑）

1. ❌ "我要写一本有文学价值的小说" → 上错了场，建议去投豆瓣阅读或纸质出版
2. ❌ "先铺垫世界观，10 万字后才正式开始" → 100% 扑街，读者在第 3 章就走光
3. ❌ "开头要文艺点" → 景物描写、心理独白 > 200 字不放主角行动，读者秒退
4. ❌ "套路被写烂了我要创新" → 新人先写套路让自己过稿活下去，拿到读者再谈创新
5. ❌ "我一天就写 1000 字" → 番茄的推荐算法对日更不稳定极度不友好
6. ❌ "我用 AI 生成章节节省时间" → 番茄已永封纯 AI 作品，AI 辅助需人工底稿

## 六、给新人作者的启示

1. **心态先转**：你是在做生意，不是在搞艺术创作
2. **读者 > 自我表达**：写之前先问"读者为什么要看完这一章？"
3. **模仿 > 原创（初期）**：前三本书都可以是"套路范本的再组合"
4. **数据 > 感觉**：自己觉得好看不算，上架后数据说了算
5. **量大 > 单章完美**：每日 4000 字、每月 10 万字的作者，比偶尔写一篇神作的作者活得好得多
6. **把自己当成读者**：随手看上 100 章别人的开头，记住哪些让你想读下去

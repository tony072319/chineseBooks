# 00 · 项目路线图

## 核心结论

1. **六个阶段循序推进**：研究 → 采集 → 分析 → 构思 → 写作 → 发布，每个阶段结束要复盘。
2. **Phase 1 是地基**，把网文"是什么、怎么写、怎么活"搞清楚再动手，能省去后面大量无效劳动。
3. **Phase 2-3 是工程化投入**，但只是手段。核心产出仍然是 Phase 5 的原创章节。
4. **Phase 5 才是真正的工作**，前面所有阶段加起来可能只需要 1-2 个月，写一本书要 **半年到两年**。
5. 首作**大概率不火**。做好心理准备：第一本书拿数据、第二本书拿成绩。

---

## 时间线（参考值，实际按投入时间浮动）

```
 0    1w   2w    3w    5w    8w               1年                        2年+
 │────│────│─────│─────│─────│────────────────│──────────────────────────│
 P1研究  P2爬虫  P3分析  P4构思   P5写作（日更）       P5.2 第二本书？
        └→      └→      └→      └→             └→ P6投稿、数据迭代
```

| Phase | 周期 | 可度量的里程碑 |
|-------|------|----------------|
| **1 研究** | 1 周 | 11 份手册写完，README 能回答"网文商业逻辑是什么"。 |
| **2 基础设施** | 1 周 | 可以跑 `python scrapers/biquge.py --book "斗破苍穹"` 把全书抓到 `corpus/raw/`。 |
| **3 采集+分析** | 2-3 周 | 入库 ≥ 30 本，每本自动生成一份 Markdown 分析报告；汇总出《网文结构数据报告》。 |
| **4 选型+大纲** | 1-2 周 | 确定类型；完成世界观、主线三卷大纲、前 20 章细纲、核心人物卡。 |
| **5 写作** | 3-24 月 | 存稿 ≥ 20 章后上架番茄；持续日更 4000 字以上。 |
| **6 投稿+迭代** | 与 5 并行 | 每月回顾数据：首日阅读、完读率、7/30 日留存、追更率。 |

## 每个阶段的"出口条件"

一个阶段没有全部打钩，**不进入下一阶段**。

### Phase 1 · 研究（当前阶段）
- [ ] 能用一段话说清楚"网文和文学有什么本质区别"
- [ ] 能说出 5 个以上主流类型及其套路
- [ ] 熟悉番茄的签约流程、稿费梯度、原创检测红线
- [ ] 3 本标杆作品（十日终焉/斗破/牧神记）各有一份解剖笔记
- [ ] 100+ 本优先阅读书单就位

### Phase 2 · 基础设施
- [ ] `scrapers/base.py` 有限速、重试、UA 轮换、错误日志
- [ ] 笔趣阁、飘天文学各有一个可用实现
- [ ] `corpus/metadata.json` 能增删查改
- [ ] 抓取成功率 > 90%，单本 1000 章可在 1 小时内抓完

### Phase 3 · 采集+分析
- [ ] 至少 30 本入库，覆盖 4 个以上类型
- [ ] `analysis/structure.py` 可输出：平均章节字数、章节数分布、更新时间轴
- [ ] `analysis/opening.py` 可识别：金手指出现章节、第一个冲突章节
- [ ] 每本生成 `analysis/reports/{书名}.md`
- [ ] 汇总出《网文结构数据报告.md》给出类型差异数据

### Phase 4 · 选型+大纲
- [ ] 选定 **一个** 类型（并写出选择理由）
- [ ] 世界观、力量体系、金手指设计成文
- [ ] 主线分 3 卷，每卷分 5-10 个章节群
- [ ] 至少 20 章的细纲（每章一句话目标 + 结尾钩子）
- [ ] 主配角各 ≥ 2 人，有完整人物卡

### Phase 5 · 写作
- [ ] 前 3 章经过 **3 次以上** 打磨
- [ ] 存稿 ≥ 20 章再上架
- [ ] 写完 10 章自检一次：爽点密度、钩子、字数、人物弧线
- [ ] 每章末尾有 **明确的下一章钩子**

### Phase 6 · 投稿+迭代
- [ ] 番茄作者后台完成实名 + 签约申请
- [ ] 上架后首日有 ≥ 400 阅读
- [ ] 10 万字时完读率 ≥ 15%（脑洞文）或 ≥ 10%（传统文）
- [ ] 每周复盘一次数据，月度总结一次

---

## 决策点（Decision Gates）

这些节点必须 **停下来问自己**：

1. **Phase 1 结束后**：类型我选哪个？还是继续采样再决定？
2. **Phase 3 数据出来后**：是否需要调整对类型的认知？
3. **Phase 5 首作写到 10 万字**：数据达标吗？不达标是改开头、换金手指，还是直接换书？
4. **首作写到 30 万字**：有没有持续更新的资源？是否转做兼职 / 全职？

---

## 给未来的自己

- 网文不是作家的游戏，是 **产品经理 + 服务员 + 写手** 的三合一
- 不要追求一次到位，**先跑通流程**，首作能写完就是胜利
- 任何时候卡住了，就回来看这份路线图，确认自己在哪个阶段，该干什么
- **已经投入的成本不是理由**。数据不好就改，改不动就换新书

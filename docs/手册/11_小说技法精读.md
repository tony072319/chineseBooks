# 11 · 小说技法精读（骨架版）

基于 31 本深读 + 49 条跨书共识，精选成 5 大类 15 条可上手技法。
本文档会分多轮逐条填充内容——**此版本是骨架，后续加血肉**。

---

## 一、人物塑造（4 条）

### 技法 1 · 主角要有"不体面的真实"

**来源**：范闲（贪心、要权要女人要钱）/宁缺（对桑桑冷漠到让小孩做重活）/路明非（自嘲"我猥琐的本质"）

**原理**：读者喜欢的不是完美，是**有缺陷但守底线**。完美主角像展品，不体面的主角才像人。

**我的 50 章错在哪**：陈烛被写成"话少、冷静、有担当、孝顺"——四个标签全是优点。没有"小毛病"，也没有"不光彩的底"。他在葬礼上不哭不闹不失态——这不是人，是演员。

**改写方向**：给他一个**不体面的真实**。比如：
- 考研二战失败那天他躲在图书馆偷偷扇了自己一巴掌，现在还会半夜想起来丢人。
- 葬礼上有个远亲给了他一个红包他收了，回老宅数钱时发现两千块，**第一反应是松了一口气**（下个月房租有了）——然后他才开始愧疚。

**自检**：写主角时问——他**最怕被看见**的一面是什么？那一面写出来了没？

### 技法 2 · 物件代心理

**来源**：陈平安被富家少年羞辱，书里不写"他自卑"，写他"站在石狮子前强忍住想摸石球的冲动，走上台阶"。

**原理**：心理活动直接说出来 = 告诉；通过物件/动作暴露 = 让读者自己读懂。后者厚十倍。

**我的 50 章错在哪**：全书频繁出现"他心里咯噔一下"、"他手按在左手手腕"、"他摸了三下"——**一个动作用了 50 次**成了滑稽的复读。并且"咯噔一下"直接把感受告诉读者，等于没写。

**改写方向**：把每一次"咯噔一下"替换成**具体物件 + 具体动作**：
- 原："陈烛心里咯噔一下。"
- 改："陈烛手里的茶还没喝，放回桌面的时候，茶杯底在木桌上发出轻轻一响。他没注意到自己的手抖了。"

**自检**：本章有没有一次心理描写**不靠形容词**，靠一个物件完成？

### 技法 3 · 配角 = 矛盾的行为模式（不是单一特征）

**来源**：《剑来》里的算命道士——既会用虚签骗钱，也会偶尔真的帮人治病。读者记住他，不是因为"骗子"标签，是因为**矛盾**。

**原理**：读者记不住"冷静的林雾"，但会记住"冷静的林雾唯独在便利店买饭团时会挑三分钟"。矛盾 = 人味。

**我的 50 章错在哪**：
- 林雾 = 冷静 + 异瞳 + 死了父亲
- 老许 = 神秘 + 博物馆 + 老
- 阿骨 = 档案 + 孤儿院
- 周队 = 警察 + 欠人情

**全是标签拼贴**。没有任何一个人物有"和自己标签反着来"的小动作。

**改写方向**：给每个 NPC **一个和主标签冲突的小习惯**：
- 林雾（冷静）→ 每次结束任务回车上会把手放在方向盘上发呆两分钟不说话。不是"累了"，是她其实**怕独处**。
- 老许（神秘隐居）→ 博物馆三楼他自己的房间里有**全套 KFC 杯子**（30 多个），他每月偷偷去吃两次。
- 阿骨（档案小姑娘）→ 她手机相册里有**300 张**自己做饭的照片。没人知道她做饭，她也没发过朋友圈。

**自检**：每个有名字的 NPC，能不能说出他**一件不符合标签的事**？

## 二、氛围 / 感官（3 条）

### 技法 4 · 给每个 NPC 一个"说话模式"

**来源**：
- 徐凤年（雪中）："老兄弟，你是徐骁请来的高人吧？" —— 自来熟、套信息
- 老头儿（雪中）：只答"人屠徐骁怎生出了你这么个儿子。有点意思。" —— 评价代对话
- 恺撒（龙族）："我以为得切腹或者化学阉割呐。" —— 黑色幽默
- 楚子航（龙族）："她心理状态不稳定。" —— 惜字如金
- 路明非：啰嗦自嘲北方口气

**原理**：不同人物的**句式、话量、口头禅**要分化，读者两次就能认出谁是谁说话。

**我的 50 章错在哪**：林雾、阿骨、老许、周队、沈栖梧——**五个人说话一个节奏**，都是"完整主谓宾 + 解释性后缀"。把他们的台词打乱贴一起，读者分不清谁是谁。

**改写方向**：
- **林雾**：只说事实，**不加修饰、不给情绪词**。"三点去。""别去。""你迟到了。"
- **沈栖梧**：**话密 + 问号多**。"老哥你这碗面加辣不？加多少？加小米椒还是剁椒？"
- **老许**：**先沉默再一句定调**。别人说完他"嗯"了好一会儿，才说："**你爷爷当年也这样。**"
- **阿骨**：**讲完事实后补一个数据**。"他死于 2002 年——档案第 47 箱，编号丁-0019。"
- **周队**：**警察口音 + "啧"开头**。"啧，这事儿得分两头说……"

**自检**：把本章所有对话剥掉"某某说"提示语，读者能不能凭句式认出谁在说话？

### 技法 5 · 物质腐朽代修饰词

**来源**：黑山老鬼《从红月开始》——"暗红色的月亮低垂在城市鳞次栉比的高楼之上……油腻的玻璃罩子"——不用"阴森"二字，全靠**物理腐朽**。

**原理**：形容词（阴森、诡异、冷）是**读者已经麻木**的信号。物理细节（锈迹、油腻、发黄的灯管）强迫读者**用眼睛看**才能理解意思。

**我的 50 章错在哪**：开篇"雨下得很细"、"秋雨很凉"——**形容词堆叠**。反复写了 50 章的"冷雨 / 灰天 / 旧老宅"但没有一个读者真的感到冷。

**改写方向**：
- 原："雨下得很细。"
- 改："雨落在墓地的水泥小道上，把昨天的脚印泡发得发白。陈烛的皮鞋边沿已经黑了一圈——那是墓地的泥，不是马路的泥。"

原句 6 个字告诉，改句 50 个字**让读者自己看出来**——下雨了、下了一晚、这里是老墓地、陈烛没穿靴子来。

**自检**：本段若把所有形容词删掉，剩下的物件和动作还能不能让读者感受到情绪？

### 技法 6 · 感官即信息（细节同时负责氛围 + 情节）

**来源**：《诡秘之主》开篇——"绯红的月亮""轻纱般的绯红"——这些颜色不是装饰，是**在告诉读者克莱恩正在从一个世界穿越到另一个世界**。感官细节**有情报价值**。

**原理**：一个好细节承担**两件事**——制造氛围 + 推进认知。坏细节只是修饰。

**我的 50 章错在哪**：我写"樟木 + 陈茶叶 + 老人汗味"——有氛围但**没情报**。换成别的味道读者也读得下去，这个细节就是可替换的废料。

**改写方向**：让每一个感官细节**指向一个秘密**：
- 原："老宅里有樟木和陈茶叶的味道。"
- 改："老宅里有樟木味道——但书房里不是。书房是**墨**的味道。陈烛愣了一下，他爷爷不写毛笔字，这栋房子里也没人写。他走进书房，才发现书桌最底下一个抽屉的锁眼**磨得发亮**——常被打开。"

樟木 vs 墨的**对比**揭露了一个秘密（书房是另一个空间），抽屉磨亮**推进**了情节（爷爷常藏东西）。**两个感官细节都在干活**。

**自检**：本段的感官细节如果换成别的（例如樟木换花椒），情节会不会改变？如果不会，这个细节是废料。

## 三、对话 / 内心（3 条）

### 技法 7 · 身体反应代情绪词

**来源**：
- 陈平安在宁姚面前被蛇咬，说"这算什么"——但"冷汗直流"暴露真相
- 庆尘面对危机不尖叫，**列清单 / 拿钥匙 / 拜菩萨 / 写遗书**——身体知道怎么活

**原理**：情绪词（紧张、害怕、难过、激动）是**告诉**。身体动作是**展示**。身体不会骗。

**我的 50 章错在哪**：陈烛情绪变化都是"心里咯噔 / 心跳加速 / 冷汗直流"——**直接用情绪词**。读者知道"他在紧张"但没真的紧张起来。

**改写方向**：
- 原："陈烛心里咯噔一下。"
- 改："陈烛把茶杯往桌面放，杯底磕到桌沿，茶水溅出来两滴。他没擦。"

改句没出现一个情绪词。但读者读到"没擦"那一下，自己会紧张——因为爱整洁的人不会不擦，他正在**注意力被别处占据**。

**自检清单**：
- 他紧张 → 有没有动作被中断 / 被遗忘 / 做错？
- 他害怕 → 有没有身体某个部位开始做不该做的事（手指敲桌、脚尖点地）？
- 他激动 → 有没有多做了一步不必要的事（倒水倒满、话说半句就停）？

### 技法 8 · 对话三层（说 A 想 B 读出 C）

**来源**：
- 许七安对小鱼："友情价，八百贯。" 表面讨价还价，**底下是**"我想把这个小财迷留下来"
- 范闲对二皇子："桑姑娘只在陈园唱曲。" 表面讲事实，**底下是**"我背后有陈萍萍"

**原理**：人物说的话 **≠** 他想说的话。读者读到的 **≠** 字面意思。三层不重合，对话才有厚度。

**我的 50 章错在哪**：陈烛和林雾对话几乎都是"A 问 B 答，信息直给"。没有人**说谎 / 遮掩 / 打岔 / 转移话题**。不像活人，像信息交接。

**改写方向**：
- 原：
  林雾："你爷爷身上那盏灯，熄了。"
  陈烛："什么意思？"
  林雾："灯只会熄一次。所以你得接手。"

- 改：
  林雾拿起茶杯，没喝，放下。
  "你爷爷身上那盏灯——"
  她停了一下，看了陈烛一眼。
  "——熄了。"
  陈烛手里还捏着那张名片。他没问"什么意思"。他知道她会继续说。她也知道他知道。
  "灯只会熄一次。"
  这不是告诉他一个规则。这是在告诉他：**她已经来过一次，跟他爷爷说过同样的话**。而他爷爷那次选择了接。

**自检**：本段对话，主角**没说出口**的那句话是什么？如果说不出，这段对话还不够。

### 技法 9 · 内心独白 = 思考过程（不是情绪）

**来源**：范闲听到林珙死讯——**三层思考**：
1. 事实判断："虽然不知道五竹怎么找到吴先生的，但以五竹性子，捅死两个幕后黑手很正常。"
2. 对手预测："既然靖王都认为我和林珙死有关，宰相会怎么想？"
3. 决策："这一辈子也不能让婉儿知道这件事。"

**原理**：内心独白不是读者看一个人"情绪起伏"，是读者**跟着他的大脑一起算账**。读者要被卷入**思维本身的快感**。

**我的 50 章错在哪**：陈烛的内心戏 = "他感到震惊 / 他觉得奇怪 / 他有点难过"——**情绪报告，没有推演**。读者不知道他到底在想什么。

**改写方向**：凡写内心戏，问自己三个问题：
1. **他现在掌握了什么事实？**
2. **他在猜对方（或情况）是怎样的？**
3. **基于这个推断，他下一步决定做什么？**

例：
- 原："陈烛心里一震——所以祖父走那天，身上的灯真的熄了。"
- 改："陈烛在脑子里把时间对上了：祖父走的那晚是周三。周二晚上他还通过电话——祖父说他在收拾书房。现在看来那不是收拾。那是**把该留的留好**。能提前一晚安排好的人，不会是'意外走'的。也就是说——祖父知道自己那晚要死。那他为什么没告诉自己？"

改句信息量密度翻倍。读者不是在看"陈烛震惊了"，是**跟着他破案**。

**自检**：本段心理戏有没有"事实 → 推断 → 决策"的痕迹？没有就删掉或重写。

## 四、节奏 / 信息控制（3 条）

11. **延迟关键信息、但不停铺垫** —— 8 章不揭底，每章都有小线索
12. **同章内部快慢交替** — 开头快、中段慢、结尾再起（不是整章一个节奏）
13. **爽点物质化** — 数值/物品/身份变化的可视证据，不是"他感到满足"

## 五、场景 / 市场（2 条）

14. **规则化紧迫感** — 给异常/能力一个量化失控指标（HP条可见代价）
15. **番茄短剧化** — 章 3500 字、台词冲突化、每 5 章一个可截图的记忆点
